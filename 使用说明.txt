========================================================
  顾圣杰学术主页 · 使用说明
========================================================

一、文件结构
------------------------------------------------
  index.html      网站唯一页面（单页应用，无需打开其它 html）
  css/style.css   样式文件
  js/data.js      ★ 所有内容都改这里（最重要）
  js/main.js      网站逻辑（一般不用动）
  images/         放图片的文件夹（可选，用到了再放）

二、怎么修改内容（添加项目 / 改研究方向 / 改服务）
------------------------------------------------
  打开 js/data.js，用记事本或 VS Code 编辑。

  1. 添加项目：
     找到 projects: [ 这一段，复制里面一整段 { ... }，
     粘贴到数组末尾，改里面的字段即可。例如：

     {
       id: "project-2",           // 唯一编号，别重复
       title: "项目名称",
       year: "2025 — 至今",
       desc: "一句话概述（列表卡片显示）",
       cover: "",                 // 封面图，填 "images/p.jpg"，留空显示虚线占位
       tags: ["PyTorch", "CV"],   // 小标签
       content: [                 // 点进详情页的正文，一段一行
         "第一段：背景动机",
         "第二段：方法技术",
         "第三段：成果结论",
       ],
       images: [],                // 详情页的图片，如 ["images/a.jpg"]
       links: [                   // 详情页的链接按钮
         { label: "GitHub", url: "https://github.com/你的用户名" },
       ],
     },

  2. 改研究方向：改 research: [ ... ] 数组里对应条目。
  3. 改服务：改 services: [ ... ] 数组里对应条目。

  字段含义：
    title    标题
    desc     卡片上的概述文字
    tags     小标签
    content  详情页正文（一段 = 一个自然段）
    sub      仅研究方向有：卡片标题上方的英文小字
    price    仅服务有：如 "Free · 双向匹配"
    icon     卡片左侧的小图标（SVG 代码，一般不用改）

  改完保存 → 刷新浏览器即可看到变化。

三、本地预览
------------------------------------------------
  直接双击 index.html 即可在浏览器打开预览。
  （建议用 Chrome 或 Edge）

四、部署到 Vercel（免费，24 小时在线）
------------------------------------------------
  方式 A：拖拽部署（最简单，一次性）
    1. 打开 vercel.com，用 GitHub 账号登录
    2. 打开 vercel.com/new，把整个文件夹拖进网页
    3. 等待部署完成，得到 xxxx.vercel.app 网址

  方式 B：连 GitHub 仓库（推荐，改完自动更新）
    见第六节。

五、绑定阿里云域名
------------------------------------------------
  1. Vercel 项目 → Settings → Domains → 输入你的域名
     （如 www.你的域名.com），记下它给的 CNAME 地址
  2. 阿里云控制台 → 域名 → 解析设置 → 添加记录：
       记录类型：CNAME
       主机记录：www（不带 www 就填 @）
       记录值：填 Vercel 给的 CNAME 地址
  3. 等待生效（几分钟到几小时），Vercel 自动配好 HTTPS

六、GitHub 仓库 + 实时自动更新
------------------------------------------------
  目标：以后改完 data.js，push 到 GitHub，网站自动更新。

  1. 装 Git：git-scm.com 下载安装（一路下一步）
  2. 在 GitHub 网页创建仓库：
       登录 github.com → 右上角 + → New repository
       仓库名随便起（如 academic-website）
       不要勾选 "Add a README"（我们要上传已有文件）
       → Create repository
  3. 在本文件夹打开命令行，依次执行：
       git init
       git add .
       git commit -m "初始版本"
       git remote add origin https://github.com/你的用户名/仓库名.git
       git push -u origin main
     （push 时需要登录 GitHub，按提示输入或弹窗授权）
  4. Vercel 连仓库：
       vercel.com → Add New → Project
       → 授权 GitHub → 选择你的仓库 → Deploy
  5. 以后每次改完内容：
       git add .
       git commit -m "更新内容"
       git push
     Vercel 会自动检测到更新并重新部署（约 1 分钟生效）。
